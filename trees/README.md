# Trees

This folder contains my practice problems related to binary trees.

## Concepts

- Binary Tree
- Tree Traversal
- DFS
- BFS
- Recursion
- Tree Height
- Time and space complexity

## Problems

| Problem | Approach | Time | Space |
|---|---|---|---|
| Maximum Depth of Binary Tree | DFS / Recursion | O(n) | O(h) |
| Same Tree | DFS / Recursion | O(n) | O(h) |
| Invert Binary Tree | DFS / Recursion | O(n) | O(h) |
| Symmetric Tree | Mirror Comparison | O(n) | O(h) |
| Balanced Binary Tree | Height + DFS | O(n) | O(h) |
