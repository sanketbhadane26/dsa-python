# Stack

This folder contains my practice problems related to stacks.

## Concepts

* Stack
* LIFO (Last In, First Out)
* Push
* Pop
* Peek / Top
* Stack traversal
* Brackets / Parentheses Matching
* HashMap with Stack
* Time and space complexity

## Problems

| Problem           | Approach        | Time                  | Space |
| ----------------- | --------------- | ----                  | ----- |
| implement stack   |  Array/List     | O(1) per operation    | O(n)  |
| Valid Parentheses | Stack + HashMap | O(n)                  | O(n)  |
| Min Stack	        | Two Stacks	  | O(1) per operation	  | O(n)  |
| Baseball Game     | Stack           | O(n)                  | O(n)  |
| Backspace String  | Compare Stack	  | O(n)	              | O(n)  |
