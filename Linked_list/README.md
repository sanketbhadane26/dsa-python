# Linked List

This folder contains my practice problems related to linked lists.

## Concepts

* Linked List
* Node
* Head
* Tail
* `next` pointer
* Traversing a linked list
* Inserting nodes
* Deleting nodes
* Reversing a linked list
* Slow and Fast pointers
* Two Linked Lists
* Detecting cycles
* Time and space complexity

## Problems

| Problem | Approach | Time | Space |
|---|---|---|---|
| Implement Linked List | Node + Traversal | O(n) | O(n) |
| Reverse Linked List | Previous + Current + Next | O(n) | O(1) |
| Merge Two Sorted Lists | Two Pointers | O(n + m) | O(1) |
| Middle of Linked List | Slow + Fast Pointers | O(n) | O(1) |
| Remove Duplicates from Sorted List | Pointer Manipulation | O(n) | O(1) |
| Linked List Cycle | Slow + Fast Pointers | O(n) | O(1) |
